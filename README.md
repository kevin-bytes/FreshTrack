# FreshTrack (Basic OOP Starter)

Introductory Java OOP project using straightforward classes, private fields, constructors, getters, inheritance, and overriding/inherited methods. JavaFX uses a simple three-tab interface: setup, results, and comparison placeholder.

This is boilerplate and has not been compiled or tested. The freshness and quantity-loss calculations are illustrative placeholders, not scientifically validated.
